分维度详查

视觉层级（Visual Hierarchy）

  • warn 概览页主从关系被 TMDB 浏览器稀释，落地页焦点分散（见 #3）。
  • pass 统计卡数字大、标签小，层级清晰；状态点 + 环形进度表达到位。
  • pass 标题用 --font-display + 负字距，区分度好。

视觉风格（Visual Style）

  • pass 扁平 admin 风格、三档边框/四级文字 token、统一圆角与留白，体系一致。
  • warn 滑块轨道、图标风格、color-mix 无回退（见 #9/#10/#5）。
  • warn 图标 sprite 在 login/index/body 三处重复，应抽共享文件。

无障碍（Accessibility）

  • fail 无 :focus-visible 全局焦点环（#2）。
  • fail 次要文字/占位符对比度不足（#4）。
  • warn 活动导航项仅用 .active 类，缺 aria-current="page"。
  • pass 原生 input/toggle/range 可用性较好；prefers-reduced-motion 已全局兜底。

导航（Navigation）

  • fail 桌面 5 项 / 移动 4 项，概览页在移动端不可达（#1）。
  • pass 侧边栏 + 顶部搜索 + 移动端抽屉 + 遮罩，模式完整。
  • warn 中等屏三栏偏挤（#12）。

可用性（Usability）

  • pass 实时日志、进度环、暂停/停止、筛选、Toast、确认弹窗反馈充分。
  • warn 搜索下拉结果键盘可达性未确认；清除按钮键盘不可用（#8）。
  • pass 登录含锁定倒计时、上次登录、密码显隐，防御与引导到位。

建议落地顺序

  1. 本周：修 #1（移动端导航）、#2（焦点环）、#6/#7（两个 bug）。成本极低、收益最高。
  2. 下周：#3（概览页减负）、#4（对比度）、#5（图表配色）。
  3. 打磨：#8–#12 统一图标、滑块主题化、Toast aria-live、中等屏断点。
